Project Overview

SmartCCTV reimagines traditional CCTV as an active safety system rather than a passive recording device. The system continuously analyses live video streams from cameras, applies YOLOv8 object detection to track vehicles and people in real time, and uses motion analysis algorithms to detect accidents the moment they happen.

When a crash or fall is detected, Twilio immediately dispatches automated SMS and voice calls to predefined emergency contacts — dramatically reducing the time from incident to response.

Detection Modules

Vehicle Crash Detection
Tracks bounding box positions of detected vehicles across frames. Sudden velocity changes, overlapping boxes, and post-collision stillness patterns trigger crash classification.
Human Fall Detection
Monitors the aspect ratio of human bounding boxes. A standing person has height > width; a fallen person's box becomes wide. Combined with velocity analysis to reduce false positives.

Processing Pipeline

1
Frame Capture
OpenCV captures frames from live CCTV feed or video file, resized to YOLOv8's input resolution for consistent inference.
2
YOLOv8 Inference
YOLOv8 runs on each frame, returning bounding boxes, class labels (person, car, truck), and confidence scores for all detected objects.
3
Motion Analysis
NumPy and Pandas track object positions, velocities, and bounding box aspect ratios across a rolling frame window to detect sudden changes.
4
Event Classification
Rule-based classifier combines YOLOv8 detections + motion metrics to decide: crash / fall / normal. Cooldown timer prevents duplicate alerts.
5
Twilio Alert Dispatch
On detection, Twilio API sends SMS with timestamp and event type to all registered contacts, plus an optional automated voice call.

Challenges & Solutions

⚠ Challenge
High false positive rate — people bending over, sitting, or parking cars were constantly triggering alerts during testing.
✓ Solution
Added multi-frame confirmation: an event only triggers if the anomaly condition persists across N consecutive frames. Combined with confidence score filtering, false positives dropped by ~80%.
⚠ Challenge
YOLOv8 inference was too slow to process every frame in real-time on CPU hardware, causing alert lag of several seconds.
✓ Solution
Implemented frame-skipping: YOLOv8 runs on every N-th frame, while tracked bounding box positions are interpolated using velocity vectors on skipped frames. Achieved real-time performance on CPU.
